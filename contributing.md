
# Внесение изменений в проект

## Как внести изменения
1. Форкните репозиторий и создайте свою ветку.
2. Сделайте изменения, следуя стандартам кода в `code-style.md`.
3. Напишите тесты для новых функций или исправлений багов.
4. Сделайте Pull Request с подробным описанием изменений.

## Интеграция с Codex
- Codex будет автоматически генерировать тесты и предложения по улучшению кода.
- Все новые функции должны быть покрыты тестами.
- При создании Pull Request используйте Codex для проверки стиля кода.
