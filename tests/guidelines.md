
# Рекомендации по написанию тестов

## Типы тестов
- **Unit-тесты**: Покрытие для утилит и отдельных функций.
- **Тесты компонентов**: Проверка правильности работы React-компонентов.
- **E2E тесты**: Использование cucumber/playwright для тестирования всего приложения.

## Написание тестов
- Тесты должны быть простыми и понятными.
- Используйте `describe` и `it` для организации тестов.
- Каждый тест должен проверять одну вещь.

Пример unit-теста:
```ts
describe('Функция add', () => {
  it('должна корректно складывать два числа', () => {
    expect(add(1, 2)).toBe(3);
  });
});
```

## Интеграция с Codex
Codex будет генерировать тесты для компонентов и утилит, следуя этим рекомендациям.
