
# Стандарты кода

## Общие рекомендации
- Использовать строгую типизацию с TypeScript.
- Писать чистый код, следуя принципам, описанным Робертом Мартином.
- Разделять бизнес-логику и разметку, используя кастомные хуки и утилиты.
- Переиспользуемые компоненты в `src/shared/ui` с использованием shadcn/ui и tailwind/css.
- Папки и названия файлов стараемся писать через lower kebab case.

## Форматирование
- Использовать Prettier для форматирования кода.
- Применять линтер ESLint с конфигурацией "airbnb".
