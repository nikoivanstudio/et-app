Мобильная вёрстка осталась основной, но десктоп больше не «одна колонка 390px»: см. артборд «Десктоп — каталог 1440».
Контент 1120px, сетка карточек 3 в ряд, горизонтальное меню вместо бургера от md:.

Визуальные языки сведены: одна кнопка (золото + тёмная тушь), один набор радиусов, одни поля 48px, акцент дашборда сведён с золотом на фото.
Зелёный остался только статусом. Обводка текста убрана везде — контраст держит скрим.

Ревью снято с этих же артбордов. Контраст измерен по пикселям фото под текстом в Chrome, не на глаз.
Варианты нарисованы рядом с текущим состоянием — выбираем, потом рисуем полноценные артборды v2 и только затем правим код.
