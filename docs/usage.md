
# Как использовать Codex в проекте

## Настройка Codex
1. Убедитесь, что в вашем проекте настроены ESLint и Prettier.
2. Добавьте файл `.codex-config.json` в корень проекта для настройки Codex.
3. Codex будет использовать ваш стиль кода и правила тестирования для генерации и исправления кода.

## Использование
- Codex может помочь генерировать тесты для утилит, функций и компонентов.
- Он будет проверять стиль кода и предлагать исправления, если необходимо.
- Codex также поможет при решении багов, предлагая возможные исправления.

Для более детальной настройки и инструкций смотрите документацию по каждому из инструментов.
